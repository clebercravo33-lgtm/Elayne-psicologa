# Agenda PWA para GitHub Pages

Arquivos:
- `index.html` — aplicativo
- `manifest.json` — configuração PWA
- `sw.js` — Service Worker/cache

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os 3 arquivos para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Abra o endereço do GitHub Pages em HTTPS.

No iPhone/iPad, abra o endereço no Safari e use **Compartilhar → Adicionar à Tela de Início**.
